# Employee Department Management System

An ASP.NET Core MVC application for managing employees and their department assignments. This project was developed as a practical task during the ITI Sohag Web Development using .NET training program.

## Features

- View employee lists and employee details.
- Create, edit, and delete employee records.
- Assign employees to departments.
- Use Entity Framework Core for database operations.
- Validate user input using Data Annotations and custom validation.
- Check email availability through remote validation.
- Enforce email uniqueness using a database index.
- Use asynchronous database operations where implemented.

## Tech Stack

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views
- Data Annotations and Custom Validation

## Getting Started

### Prerequisites

- Visual Studio with ASP.NET and web development components
- .NET SDK compatible with the project
- SQL Server

### Setup Instructions

1. Clone or download this repository.
2. Open the solution in Visual Studio.
3. Update the SQL Server connection string in `appsettings.json`.
4. Restore the required NuGet packages.
5. Ensure the database schema is created and available. Apply Entity Framework Core migrations if they are included in the project.
6. Run the application from Visual Studio.
7. Open the local URL displayed when the application starts.
